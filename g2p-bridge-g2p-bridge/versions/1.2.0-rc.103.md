### Summary

_All changes since release 1.1.0:_

- Removed the legacy Keymanager crypto backend, eliminating dead signing code and related dependencies (keycloak-init, chart/config/docs).
- Changed the fastapi version to 'develop' for consistency across builds.
- Updated SPAR build dependency to point to gitlab spar@develop, replacing the previous github openg2p-spar@2.0.
- Fixed mapper initialization order in connectors to ensure proper functionality.
- Moved connectors to g2p-bridge-connectors; Celery now pulls them by git reference.
