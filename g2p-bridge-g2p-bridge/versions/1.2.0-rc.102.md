### Summary

_All changes since release 1.1.0:_

- Removed the legacy Keymanager crypto backend, eliminating dead signing code and related dependencies.
- Pointed SPAR build dependency to GitLab, switching from GitHub to `gitlab spar@develop`.
- Moved connectors to `g2p-bridge-connectors`, allowing the Celery image to pull them by git reference.
- Fixed mapper initialization order for connectors to ensure proper functionality.
