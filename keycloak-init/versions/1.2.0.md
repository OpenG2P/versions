### Release notes

keycloak-init 1.2.0 sets the CI pipeline proper for the repo

### Summary

- **Major:** Migration to GitLab for CI/CD, dropping GitHub Actions and reconfiguring workflows to use GitLab CI with updated chart pointing to the GitLab registry.
- User management enhancements: Added options to disable client authentication, introduced WebOrigin, and implemented checks to prevent script crashes when users already exist.
- Realm customization: Enabled realms to set their display names on login pages, improving user experience.
- Versioning updates: Corrected image tags and development versioning, ensuring consistency in deployments.
- Sync and stability improvements: Fixed sync issues when the registry is uninstalled and addressed issues related to user first and last name handling.
