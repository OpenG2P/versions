### Summary

- **Major:** Updated Dockerfiles and Helm chart to version 1.2.2, ensuring consistency across services and enhancing farmer registration metadata.
- Data integrity improvements: Fixed issues allowing disability details to be added incorrectly, eliminated duplicate data creation during change requests, and implemented automatic removal of disability records when status changes.
- UI/UX enhancements: Introduced a new tab for socio-economy in the farmer registration interface, improved age handling, and added fallback middle names in seed data.
- SQL metadata updates: Refactored and enhanced SQL configurations for household farmer personal information, including new fields for income sources and improved validation rules.
- Performance testing: Collected extensive performance data for async searches, partner ingestion, and various test scenarios, including soak tests and CPU monitoring adjustments.
- CI/CD transition: Migrated continuous integration from GitHub Actions to GitLab CI, streamlining the build and publish processes.
- Documentation updates: Reworked and moved documentation to a dedicated repository, enhancing clarity and accessibility for developers.
