**Chart:** [openg2p-farmer-registry 0.0.0-develop.196](https://openg2p.github.io/openg2p-helm/openg2p-farmer-registry-0.0.0-develop.196.tgz)

### Summary

- **Major:** Transitioned repository to GitLab, rendering GitHub read-only with build/publish disabled.
- Versioning updates: Incremented RP version multiple times to 0.0.0-develop.417, ensuring consistency across deployments.
- Feature enhancements: Enabled VC issuance by default, required registrant authentication for claim-169 QR config, and added farmer credential issuance behind a disabled-by-default switch.
- Data management improvements: Normalized foundational ID, fixed full name spacing in VC views, and seeded the pack's real birth date to avoid shared birthdays among sample farmers.
- Reporting optimizations: Updated SQL insert statements for g2p_register_sections and registry_languages, refreshed reporting views on a schedule, and generated fr_rpt_crop from declarations instead of hand-written SQL.
- Configuration updates: Created VC card ConfigMap on agent portal deployment and enabled the agent portal by default, while dropping duplicated VC questions from the registry subchart.
