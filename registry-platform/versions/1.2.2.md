### Summary

- **Major:** Updated Helm charts to include OIDC client ID and secret for staff portal API, and set default partner signature and consent to off, impacting deployment configurations.
- Enhancements to intake functionality: added support for cross-register submissions, improved inflight register parent retrieval with search and pagination, and integrated filtering in change request and intake forms.
- Significant updates to notification features: integrated Novu configuration in Helm, enhanced notification payloads to include subscriber details, and added functionality to notify staff and registrants on key events.
- Refactored core components: streamlined document handling and validation processes, improved session management with async session makers, and enhanced caching mechanisms for better performance.
- UI improvements: enhanced widget functionality with tooltips and improved input behavior, added financial address and bank branch widgets, and improved responsiveness across various UI components.
- Dependency updates: updated multiple packages including openg2p-notification to v1.0.0, FASTAPI_COMMON_REF to 1.3.0, and ensured Redis support in Celery configurations.
- Fixes and optimizations: addressed various bugs in API endpoints, improved error handling in intake form submissions, and refined search functionality across services for better performance.
