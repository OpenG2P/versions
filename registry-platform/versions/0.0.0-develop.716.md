**Chart:** [openg2p-registry 0.0.0-develop.716](https://openg2p.github.io/openg2p-helm/openg2p-registry-0.0.0-develop.716.tgz)

### Summary

- **Major:** Transition to `fastapi-common` for cryptographic functions, removing the deprecated `openg2p-fastapi-auth` package from images.
- Feature enhancements: Added support for optional registry-connector in Helm, improved Keycloak URL handling, and enhanced notification features including HMAC and integration with Novu.
- Functional testing improvements: Refactored workflows to separate API and UI jobs, enhanced document handling, and updated MinIO configurations for better testing environments.
- UI responsiveness: Multiple fixes to improve the responsiveness of various components including data models, registers, and intake pages.
- WebSub integration: Updated to use the commons WebSub hub, with enhancements to fail gracefully on request denial and support for async search on partner topics.
- Dependency updates: Bumped `fastapi-common` version and removed redundant dependencies, ensuring cleaner builds and improved compatibility.
- Miscellaneous fixes: Addressed various issues including behavior changes in the `SelectWidget`, improved navigation reliability, and clarified API job names in workflows.
