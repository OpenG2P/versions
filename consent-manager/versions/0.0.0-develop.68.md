### Summary

- **Major:** New consent record download feature for partners, providing a ZIP file with the original receipt, uploaded evidence, and a CM-signed statement, with SHA-256 verification against national-ID authentication.
- Enhanced national-ID login integration in the partner portal, utilizing authorization code + PKCE, private_key_jwt, and individual ID matching, now mandatory for submission and approval processes.
- Improved handling of CM approvals inbox when AWE approvals are disabled, displaying an empty list instead of a 404 error, with appropriate messaging in the console.
- Comprehensive testing added for new features, ensuring robustness and compliance with security standards.
