### Summary

- Dependency updates: fastapi-common upgraded to 1.2.0 and pinned to version 1.2 in multiple locations; keycloak-init version pinned to a published release.
- Data management enhancements: geo level value management now supports data policy; national IDs normalized during country pack loading; birth_date column added to sample individuals table with a migration strategy for existing environments.
- API improvements: geo endpoints added to MASTER_DATA_CSRF_EXCLUDED_PATHS for server-to-server API calls between mds and registry.
- Repository management: transitioned to read-only GitLab repository for master-data-service, with build and publish processes disabled.
- Code quality: applied pre-commit formatting across the repository, addressing various formatting issues without functional changes.
