### Summary

- **Major:** Database connection pooling configuration added to master-data API, enhancing performance and resource management.
- Geo enhancements: New geo endpoints added to MASTER_DATA_CSRF_EXCLUDED_PATHS for server-to-server API calls, improved geo hierarchy management with dynamic UI updates and caching, and error handling enhancements in Geo components.
- UI improvements: Master data UI redesigned for better user experience, with refactoring of Geo and Attribute components for consistency.
- Data model updates: New prefixes and relationship attributes added to g2p_attribute_values and g2p_attributes tables, along with removal of obsolete agricultural and social codelists and schema simplifications.
- Dependency updates: Keycloak, IAM, and FastAPI common libraries updated to their latest versions, ensuring compatibility and feature enhancements.
- Pre-commit fixes and deployment adjustments made for improved code quality and deployment processes.
