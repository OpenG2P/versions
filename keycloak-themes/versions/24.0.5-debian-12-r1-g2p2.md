### Release notes

Added Agent portal login page theme. Rebuilt on Docker Hub after the move back to GitHub — same source tree as the GitLab-era g2p2.

### Summary

- **Major:** CI/CD overhaul: switched from GitHub Actions to GitLab CI, removed GitHub artifacts, and updated pipeline inputs for image tagging.
- New features: added Agent portal UI theme and OpenG2P-Admin, updated favicon, and replaced Keycloak logo with OpenG2P branding.
- Bug fixes: resolved issues with user password changes affecting fallback themes and fixed various theme-related problems.
- Documentation: added a README for better project guidance and published themed Keycloak image tags to the versions catalogue.
