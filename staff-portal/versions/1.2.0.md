### Summary

- **Major:** New CI implementation enhances build processes and efficiency.
- Security improvements: added client-side CSRF token handling and updated authentication cookie management with cookieDomain configuration.
- Refactoring efforts: streamlined authentication handling in API routes, improved logout handling, and introduced an IconDisplay component for better icon management.
- Docker optimizations: updated Docker image to version 1.2, removed redundant layers from the Dockerfile, and eliminated the obsolete tag workflow.
- Documentation updates: revised README to reflect the migration to GitLab.
