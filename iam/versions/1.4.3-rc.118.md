### Summary

- **Major:** Refactor database session management to utilize `get_async_session_maker` across services, enhancing session handling.
- Keycloak integration: Added initialization configuration and IAM admin user settings, along with fixes for Keycloak base URL templating in IAM APIs.
- Dependency updates: Bumped `FASTAPI_COMMON_REF` to 1.2.1 and updated `fastapi-commons` to 1.2.0, aligning version numbers to 1.4.2.
- UI consistency improvements: Added missing translations and updated translation keys, alongside a refactor of `GeoLocationPickerModal` for better state management.
- Session management enhancements: Updated Redis token TTLs and cache expiration settings for improved performance.
- Miscellaneous changes: Removed `include_domains` from attribute API calls and refactored `DataPoliciesTab` layout.
