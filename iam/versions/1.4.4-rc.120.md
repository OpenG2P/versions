### Summary

- Configuration updates: Added Keycloak initialization settings and updated redirect URI in `values.yaml`, along with IAM admin user settings.
- Dependency management: Bumped `FASTAPI_COMMON_REF` to 1.2.1 and updated `fastapi-commons` to 1.2.0, aligning version numbers across multiple files.
- Database improvements: Refactored session management to utilize `get_async_session_maker` across services and updated Redis token TTLs for better session management.
- UI enhancements: Added missing translations and updated translation keys for consistency, along with refactoring the `GeoLocationPickerModal` for improved state management.
- JWT validation: Refactored to use `CryptoFactory` and updated related tests for component registration.
- API adjustments: Removed `include_domains` from request payloads in attribute API calls and fixed templating for Keycloak base URL in IAM Staff and Agent APIs.
